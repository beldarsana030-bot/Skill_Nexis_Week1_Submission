# 🏧 Mini Project — Simple ATM Simulator

The **Simple ATM Simulator** is a menu-driven Python application that demonstrates the use of loops, conditional statements, functions, and basic input validation.

## ✨ Features

- 🔐 PIN-based user login
- 🔢 Limited login attempts
- 💰 Check account balance
- 💵 Deposit money
- 💸 Withdraw money
- ⚠️ Insufficient balance checking
- ✅ Input validation
- 📋 Menu-driven interface
- 🧩 Separate functions for different ATM operations
