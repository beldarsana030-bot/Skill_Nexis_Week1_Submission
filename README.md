# Week 1 Submission

## Overview

This repository contains the Week 1 Python practice work and mini-project.

The work focuses on fundamental Python programming concepts, including:

- Variables and data types
- Input and output
- Operators
- Conditional statements
- Loops
- Functions
- String manipulation
- Basic list usage
- Modules

## Mini Project — Simple ATM Simulator

The `project` folder contains the Week 1 mini-project: **Simple ATM Simulator**.

### Features

- PIN-based user login
- Maximum login attempts
- Check account balance
- Deposit money
- Withdraw money
- Balance validation before withdrawal
- Input validation for amounts
- Menu-driven interface
- Separate functions for ATM operations
- Exit option

### Demo Details

The program uses the following initial values for demonstration:

- **PIN:** `1234`
- **Starting balance:** `Rs. 1000.00`

These are demo values for the project and are not intended to represent a real banking system.

## How to Run

Make sure Python 3 is installed.

### Run the ATM Simulator

From the project directory:

```bash
python project/atm_simulator.py
```

Enter the demo PIN:

```text
1234
```

### Run a Practice Program

For example:

```bash
python practice/02_even_odd.py
```
